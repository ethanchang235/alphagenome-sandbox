# Contributing

This is a personal educational project. Contributions that improve educational value or technical quality are welcome.

## Reporting Issues

- Check if the issue already exists
- Create a new issue with clear title and description
- Include steps to reproduce for bugs
- Mention your environment (OS, browser, Python version)

## Code Contributions

1. Fork the repository
2. Create a branch for your changes
3. Make changes with clear commit messages
4. Test thoroughly
5. Submit a pull request

## Areas for Contribution

**Educational Content:**
- Additional example variants
- Improved educational explanations
- Links to scientific papers

**Technical:**
- Better visualizations
- Performance improvements
- Additional tissue types
- Mobile responsiveness

**Documentation:**
- Setup guides
- API documentation

## Guidelines

- Follow PEP 8 for Python
- Use ESLint/Prettier for TypeScript/React
- Cite reputable sources for educational content
- Verify accuracy of genetic concepts
- Maintain educational/non-commercial nature
- Do not remove legal disclaimers
- Never commit API keys

## Questions

Open an issue for questions about contributing.
